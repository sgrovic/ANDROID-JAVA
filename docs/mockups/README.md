# Budget Project UI mockups

`budget-project-v1.png` is the initial visual concept for the Budget Project screen.

`budget-project-v2.png` revises the hierarchy so Budget breakdown appears first, with its section heading outside the card for consistency.

`budget-project-multi-project-v3.png` proposes the multi-project flow: the Project tab first shows separate savings goals, then opens a goal-specific breakdown and contribution view.

`contribution-split-v1.png` proposes conditional split controls for contributions assigned to both cutoffs: ratio selection, higher-cutoff selection, and a calculated amount preview.

`contribution-auto-optimize-v1.png` proposes a compact balance icon in the Contributions header that previews and applies allocations designed to keep both projected cutoff balances healthy.

These files are design references only; implementation should continue to use Android XML and Material Components.
